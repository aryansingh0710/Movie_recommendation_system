# 🎬 Movie Recommendation System

🚀 A Machine Learning-based system that recommends movies to users based on their preferences using **content-based and collaborative filtering techniques**.

---

## 📌 Project Overview
The Movie Recommendation System suggests movies similar to a user’s interests.  
It uses **data analysis and similarity algorithms** to provide personalized recommendations, just like Netflix or Amazon Prime.

---

## 🎯 Objectives
- Recommend movies based on user preferences  
- Build a similarity-based recommendation engine  
- Analyze movie metadata (genres, cast, keywords)  
- Provide an interactive UI for users  

---

## 🛠️ Tech Stack
- **Python**
- **Pandas, NumPy**
- **Scikit-learn**
- **NLTK (for text processing)**
- **Streamlit (for UI)**

---

## 📊 Features
- 🎥 Search for any movie  
- 🔍 Get top similar movie recommendations  
- 📈 Content-based filtering using cosine similarity  
- 🌐 Interactive web app  

---

## 🧠 Algorithm Used
- Content-Based Filtering  
- Cosine Similarity  
- TF-IDF / Count Vectorization
